# BLACKOUT

BLACKOUT is a personal cultural project by Von.

It is part zine, part listening room, part history notebook,
part street-art wall, and part personal archive.

The project focuses on:

- Black culture
- POC cultures
- graffiti and street art
- hip-hop and rap
- reggae
- music discovery
- audiobooks
- Black history
- Latino history
- Indigenous history
- Asian American history
- LGBTQ+ history
- civil rights
- human rights
- political philosophy
- literature
- poetry
- photography
- film
- activism
- personal writing
- community
- liberty

## How to put BLACKOUT on GitHub Pages

1. Create a new GitHub repository.

2. Give it whatever name you want.

3. Upload every file from this project into the repository.

4. Make sure the files are in the repository's main/root directory.

5. Go to:

Settings → Pages

6. Under "Build and deployment", choose:

Deploy from a branch

7. Select:

Branch: main

Folder: / (root)

8. Press Save.

GitHub will create the website.

## Important

The website does not require:

- a database
- a server
- paid hosting
- Node.js
- React
- PHP
- a backend

It is simply:

HTML + CSS + JavaScript.

## Journal

The journal uses browser localStorage.

That means journal entries are stored locally in the
browser being used.

They are not sent to a server.

Clearing browser/site storage can delete them.

## Images

The current version intentionally uses CSS-created artwork
instead of automatically copying images from the internet.

When adding photographs, artwork, album covers, or other
visual material, check the copyright/license status first.

Public-domain and appropriately licensed material is preferred.

## Design philosophy

BLACKOUT is intentionally not a polished corporate website.

It uses:

- graffiti
- zines
- newspaper layouts
- photocopy aesthetics
- handwritten typography
- stickers
- posters
- tape
- rough edges
- muted earth tones
- occasional bright graffiti colors
- album-cover energy
- editorial typography

The goal is for the site to feel alive.
